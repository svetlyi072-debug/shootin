# Моды для ShootIn — руководство автора

Чтобы сделать мод, **исходники игры не нужны** и ставить какую-то особую версию игры тоже не надо:
мод — это папка (или `.zip`) с текстовыми файлами и картинками. Игра сама находит её, показывает
в разделе **«Моды»** главного меню, и игрок включает мод галочкой.

В моде можно сделать:

| Что | Как | Нужен код? |
|---|---|---|
| Свои **уровни** | файлы `levels/*.txt` — карта символами | нет |
| Своих **врагов** (ходячих, метателей, засаду из земли) | файлы `enemies/*.json` + картинки | нет |
| Своих **боссов** с набором атак | файлы `bosses/*.json` + картинки | нет |
| Свою **кампанию** (порядок уровней) | поле `campaign` в `mod.json` | нет |
| Свою **музыку** уровня | `.ogg` / `.mp3` и строка `music:` в уровне | нет |
| Любое **поведение**: хуки на события игры, особые враги и боссы | скрипты `scripts/*.gd` (GDScript) | да |

Быстрее всего начать с готовых примеров и шаблона в папке `mods/` рядом с игрой:

* `mods/_template/` — пустой шаблон: скопируйте, переименуйте (без `_` в начале) и меняйте;
* `mods/frost_crypt/` — мод **без кода**: 3 врага, босс, 2 уровня;
* `mods/vampire_rage/` — мод **со скриптами**: хуки и свой скрипт врага.

---

## 1. Как установить мод (для игроков)

Любой способ, на выбор:

1. **Из меню:** «Моды» → **«Установить из файла…»** и выбрать скачанный `.zip`.
2. **По ссылке:** «Моды» → вставить ссылку `https://…` на `.zip` → **«Скачать и установить»**
   (принимаются только `https`-ссылки; размер до 100 МБ).
3. **Вручную:** положить папку мода или `.zip` в папку модов («Моды» → **«Открыть папку модов»**).

Где игра ищет моды (если мод с одним `id` есть в нескольких местах — берётся первый):

1. папка `mods` рядом с игрой (рядом с exe);
2. папка пользователя: `user://mods` — на Windows это `%APPDATA%\Godot\app_userdata\ShootIn\mods`
   (сюда ставит меню «Моды»);
3. `res://mods` — только когда игра запущена из редактора Godot.

Папки и архивы, имя которых начинается с `_` (например `_template`), игра пропускает.

**Включение.** Моды без скриптов включаются сами. Мод **со скриптами** выключен, пока вы не поставите
галочку и не подтвердите окно предупреждения: скрипты выполняются внутри игры с её правами, поэтому
включайте только моды из надёжных источников (см. раздел 8). Если автор обновил скрипты, подтверждение
понадобится снова. Выбор запоминается в `user://mods.cfg`.

**Играть.** Выберите мод в списке → **«Играть: …»** → сложность. Кампания мода идёт отдельно от основной
игры: у неё свой прогресс (кнопка «Продолжить с уровня N»), основная игра не затрагивается.

## 2. Структура мода

```
my_mod/                     (папка или my_mod.zip — mod.json должен лежать в корне)
├── mod.json                ← описание мода (обязательно)
├── enemies/*.json          ← свои враги
├── bosses/*.json           ← свои боссы
├── levels/*.txt или *.json ← уровни
├── sprites/*.png           ← картинки (полосы кадров)
├── music/*.ogg | *.mp3     ← музыка уровней
└── scripts/*.gd            ← скрипты (необязательно)
```

В `.zip` допускается одна папка-обёртка («МойМод/mod.json») — игра её найдёт. Чтобы собрать архив,
заархивируйте **содержимое** папки мода.

### mod.json

```json
{
  "id": "my_mod",
  "name": "Мой первый мод",
  "version": "1.0.0",
  "author": "Ваше имя",
  "description": "Одна-две фразы о моде.",
  "api": 1,
  "scripts": ["scripts/main.gd"],
  "campaign": {"title": "Моя кампания", "levels": ["levels/01_start.txt", "levels/02_boss.txt"]}
}
```

| Поле | Что значит |
|---|---|
| `id` | **обязательно.** Латиница, строчные, цифры, `_` и `-`, 2–40 символов. Уникален: два мода с одним id — второй не загрузится. |
| `name`, `version`, `author`, `description` | показываются в меню «Моды» |
| `api` | версия API модов, для которой сделан мод (сейчас `2`; моды без настроек и новых помощников остаются `1`). Если у игры API меньше — мод отклоняется с понятным сообщением |
| `scripts` | точки входа — скрипты, которые игра запускает при включении мода (по умолчанию `scripts/main.gd`, если он есть) |
| `settings` | **API 2.** Настройки, которые игрок меняет в меню «Моды» (см. «Настройки мода» ниже) |
| `campaign` | `title` и список `levels` по порядку. Если поля нет — кампания из всех уровней папки `levels/` по алфавиту. Поэтому называйте файлы `01_…`, `02_…` |

Все остальные файлы находятся по имени папки (`enemies/`, `bosses/`, `levels/`), поэтому
перечислять их в `mod.json` не нужно.

### Настройки мода (API 2)

Мод может дать игроку настройки: в меню «Моды» у выбранного мода появляется блок «Настройки мода». Значения запоминаются
(`user://mod_settings.cfg`), скрипт мода читает их через `get_setting("id")`. Меняются они в меню, поэтому действуют со следующего забега
(скрипт может сразу узнать об изменении хуком `_setting_changed`).

```json
"api": 2,
"settings": [
  {"id": "ultra", "type": "bool", "title": "Ультра-хардкор", "default": false,
   "description": "Любой полученный урон — смерть."},
  {"id": "difficulty", "type": "choice", "title": "Сложность", "options": ["Сложная", "Нормальная", "Лёгкая"], "default": 0},
  {"id": "waves", "type": "number", "title": "Волн врагов", "min": 1, "max": 10, "step": 1, "default": 3}
]
```

| Поле | Что значит |
|---|---|
| `id` | строчные латинские буквы, цифры и `_`, начинается с буквы, до 32 символов; уникален в моде |
| `type` | `bool` (галочка), `choice` (список; в скрипт приходит **номер** варианта с нуля), `number` (ползунок; `min`, `max`, `step`) |
| `title`, `description` | подпись и пояснение под ней |
| `default` | значение, пока игрок ничего не выбирал (число приводится к `step`, номер варианта — к списку) |

Неправильная настройка пропускается с сообщением в разделе «Моды» (см. раздел 10), остальные работают.

## 3. Картинки и анимации

Анимация — **полоса кадров**: один PNG (можно и `webp`/`jpg`), кадры стоят подряд слева направо,
все одного размера. Фон — прозрачный. Персонаж по умолчанию смотрит **вправо**
(если влево — `"faces_left": true`).

Описание спрайта (поле `sprite` у врага или босса):

```json
"sprite": {
  "frame": [160, 111],
  "fps": 8,
  "scale": 1.2,
  "animations": {
    "idle":   "sprites/idle.png",
    "move":   {"file": "sprites/run.png", "fps": 10},
    "attack": {"file": "sprites/attack.png", "fps": 12, "loop": false},
    "closed": {"file": "sprites/death.png", "first": 5, "count": 1},
    "wake":   {"file": "sprites/death.png", "reverse": true}
  }
}
```

| Поле | Значение |
|---|---|
| `frame` | размер одного кадра `[ширина, высота]` в пикселях (на уровне спрайта — для всех анимаций; можно задать и у отдельной анимации). Не указан — кадры квадратные по высоте картинки |
| `fps` | кадров в секунду (по умолчанию 8) |
| `scale` | во сколько раз увеличить (по умолчанию 1; клетка карты — 32 px, игрок — 48 px высотой, средний враг ≈ 55–65 px) |
| `offset` | сдвиг картинки `[x, y]`. **Обычно не нужен:** по первому кадру `idle` игра сама ставит ноги на землю и центрирует тело |
| `faces_left` | `true`, если на картинках персонаж смотрит влево |
| `animations` | словарь «название → файл» или «название → объект» |
| у анимации: `file`, `fps`, `loop`, `first` (с какого кадра), `count` (сколько кадров), `reverse` (задом наперёд), `frame` | `loop` по умолчанию `true` для `idle`, `move`, `walk`, `run`, `closed`, `windup`, `summon` и `false` для остальных |

Картинки читаются прямо из мода (и из `.zip` тоже), перекодировать или импортировать их не нужно.

## 4. Враги (`enemies/*.json`)

```json
{
  "id": "frost_ghoul",
  "name": "Ледяной гуль",
  "symbol": "G",
  "stats": {"health": 60, "reward": 15, "speed": 2.3, "aggro_range": 7,
            "attack_range": 1.2, "attack_damage": 12, "attack_cooldown": 1.4,
            "attack_duration": 0.45, "attack_hit_time": 0.22, "dodge_chance": 0.0},
  "sprite": { "...": "см. раздел 3" }
}
```

* `symbol` — **один символ**, которым враг ставится на карту уровня. Нельзя `. # - ^ + E P`, пробел и символы,
  занятые игрой (`s b k g m r c p z y x M N O W V B K Z o * f T`). У каждого мода символы свои: два мода
  могут использовать одну букву, уровень видит в первую очередь символы своего мода.
* `id` и `name` — имя (для людей и сообщений об ошибках).

### Параметры `stats` (все необязательные)

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `health` | здоровье | 20 |
| `reward` | сколько силы получает игрок за убийство | 10 |
| `speed` | скорость в клетках/с | 3 |
| `aggro_range` | с какого расстояния (клетки) замечает игрока | 6 |
| `attack_range` | дистанция удара (клетки) | 1 |
| `attack_damage` | урон удара | 10 |
| `attack_cooldown` | пауза между ударами, с | 1,2 |
| `attack_duration`, `attack_hit_time` | длительность удара и момент урона от начала замаха, с — подгоняются под анимацию | 0,5 и 0,25 |
| `dodge_chance` | шанс увернуться от пули, 0–1 | 0,4 |
| `flee_below_health` | убегает, когда здоровья меньше этой доли (0–1) | 0 |
| `corpse_time` | сколько секунд лежит тело | 1 |
| `can_jump` | прыгает через блоки на пути к игроку (`true`/`false`) | false |

Неизвестный параметр не ломает мод — игра предупреждает о нём в консоли.

### Названия анимаций врага

`idle` (стоит), `move` (бежит; подойдут и `run`/`walk`), `attack`, `hurt` (получил удар; подойдут `hit`/`take_hit`),
`death`. Дополнительно — `throw` (бросок), `closed` и `wake` (засада). Нужны минимум `idle`; чего нет — подставляется
запасная анимация. Если хочется называть по-своему: `"animation_names": {"move": "shuffle", "hurt": "ouch"}`.

### Метатель: `throw`

```json
"throw": {"projectile": "bolt", "damage": 12, "cooldown": 3.2, "min_range": 3, "max_range": 8,
          "scale": 1.2, "explode_radius": 1.0}
```

Враг держит дистанцию `min_range…max_range` клеток и бросает снаряд по дуге с упреждением.
`projectile` — имя встроенного снаряда (`fireball`, `bolt`, `spore`, `bomb`, `sword`) или свой, см. «Снаряды».

### Засада из земли: `dormant`

```json
"dormant": {"wake_range": 2.2, "wake_time": 0.9, "lying_height": 14}
```

Враг лежит (анимация `closed`), пока игрок не подойдёт ближе `wake_range` клеток или не ударит его,
потом встаёт (анимация `wake`, `wake_time` секунд). `lying_height` — высота тела (px), пока лежит.
Чтобы «встать из земли», сделайте `wake` из кадров смерти задом наперёд (`"reverse": true`), а `closed` — из
последнего кадра смерти (см. `mods/frost_crypt/enemies/crawler.json`).

### Снаряды

`projectile` (у метателя или атаки босса) — либо имя встроенного снаряда, либо своё описание:

```json
"projectile": {
  "frame": [24, 24],
  "fly":     {"file": "sprites/shard.png", "fps": 12},
  "explode": {"file": "sprites/shard_hit.png", "fps": 16}
}
```

## 5. Боссы (`bosses/*.json`)

Босс описывается теми же полями `id`, `name`, `symbol`, `sprite`, плюс `stats` и список **атак**:

```json
{
  "id": "frost_lord", "name": "Ледяной лорд", "symbol": "L",
  "stats": {"health": 260, "smart_health_multiplier": 1.5, "speed": 2.0, "stop_distance": 2.0,
            "arena": 14, "activation_range": 14, "enrage_at": 0.5, "max_minions": 4},
  "sprite": { "...": "..." },
  "attacks": [
    {"type": "melee", "range": 2.3, "damage": 16, "interval": 1.4, "windup": 0.22, "animation": "attack"},
    {"type": "projectile", "pattern": "fan", "projectile": "bolt", "count": 3, "enraged_count": 5,
     "spread": 14, "speed": 9, "damage": 10, "interval": 5, "min_range": 3, "animation": "attack2"},
    {"type": "shockwave", "radius": 9, "speed": 9, "damage": 18, "interval": 8, "animation": "smash"},
    {"type": "summon", "enemy": "G", "count": 2, "interval": 14, "near_player": true},
    {"type": "charge", "speed": 10, "damage": 20, "interval": 9, "windup": 0.7}
  ]
}
```

### stats босса

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `health` | здоровье (на лёгкой сложности — как есть) | 20 |
| `smart_health_multiplier` | во сколько раз больше здоровья на нормальной и сложной | 1 |
| `speed` | скорость шага, клеток/с | 2 |
| `stop_distance` | на каком расстоянии от игрока останавливается, клетки | 2 |
| `arena` | полуширина арены в клетках от места появления: дальше призывы, таран и прыжки не заходят (и сам босс при `boss_leash` в уровне) | 12 |
| `activation_range` | с какого расстояния просыпается, клетки | 14 |
| `enrage_at` | при какой доле здоровья звереет (атакует на четверть чаще, `enraged_count`) | 0,5 |
| `max_minions` | сколько призванных помощников может быть живыми | 4 |
| `reward` | сила за победу | 0 |

На **лёгкой** сложности боссы стоят на месте, бьют реже, не зовут помощников и не таранят — как и встроенные.

### Атаки

Атаки перебираются **по порядку**: босс берёт первую, у которой прошла пауза `interval` и подходит расстояние.
Поэтому самые частые и ближние ставьте раньше. Общие поля любой атаки:

| Поле | Значение |
|---|---|
| `type` | `melee`, `projectile`, `shockwave`, `summon`, `charge` |
| `interval` | пауза между этой атакой, с |
| `first_delay` | через сколько с можно впервые (по умолчанию половина `interval`) |
| `windup` | замах: через сколько с после начала сработает атака |
| `recover` | пауза после неё, с |
| `animation` | какая анимация (по умолчанию `attack`); нет такой — `idle` |
| `min_range`, `max_range` | на каком расстоянии до игрока (клетки) атака годится |
| `smart_only` | `true` — только на нормальной и сложной |

| Тип | Поля (по умолчанию) |
|---|---|
| `melee` | `range` (2) — дальность, `damage` (12) |
| `projectile` | `pattern`: `aimed` (с упреждением), `fan` (веер без упреждения), `lob` (по дуге на место, куда игрок придёт), `rain` (сверху на ±`width` клеток вокруг игрока с красными метками, как у огненного червя). `projectile` — снаряд; `count` (1), `enraged_count`, `gap` (пауза между шарами, 0,3), `speed` (8), `damage` (10), `spread` (угол веера, 10°), `gravity`, `scale`, `radius`, `explode_radius`, `mouth` (откуда вылетает `[вперёд, вверх]` в клетках, `[1.2, -0.8]`); для `lob`: `flight_time` (1), `spread_tiles` (1,5); для `rain`: `waves` (2), `wave_gap`, `width` (8), `spacing` (1,8), `height` (12), `warning` (0,8), `window` (2,5 — ширина «окна» без шаров) |
| `shockwave` | `radius` (8 клеток), `speed` (9), `damage` (15) — волна по земле в обе стороны, **перепрыгивается** |
| `summon` | `enemy` — символ врага (свой или встроенный, например `"s"`), `count` (2), `near_player` (появляются рядом с игроком, иначе у босса). Только на умной сложности |
| `charge` | таран через арену: `speed` (10), `damage` (20), `max_time` (1,5); перед броском босс дрожит и краснеет `windup` секунд — игрок успевает отойти |

Названия анимаций босса: `idle`, `walk` (или `run`/`move`), `run` (таран), `hit` (или `hurt`), `death`
и любые, указанные в `animation` атак.

## 6. Уровни (`levels/*.txt` или `*.json`)

### Формат txt

```
title: Ледяной зал
theme: stone
require_clear: no
win_boss: L
music: music/hall.ogg

....................................
.....+.............................
..P.....G.....J.........Q......E...
####################################
```

Сначала **заголовок** — строки `ключ: значение`, потом **пустая строка**, потом **карта**: каждый символ — клетка 32×32 px.
Заголовок можно не писать — тогда карта начинается с первой строки.

| Ключ | Значение |
|---|---|
| `title` | название (по умолчанию — имя файла) |
| `theme` | материал блоков и фон: `grass`, `meadow`, `clay`, `candy`, `stone`, `crypt`, `wood`, `jade`, `brick` (по умолчанию `grass`) |
| `require_clear` | `yes` — выход откроется, только когда не останется врагов |
| `win_boss` | символ босса, победа над которым завершает уровень (иначе — над любым боссом, если выхода нет) |
| `boss_leash` | `yes` — боссы не уходят дальше своей арены (для огромных карт) |
| `boss_arena` | полуширина арены по боссам: `boss_arena: M=12 L=22` |
| `zones` | оформление по зонам: `zones: 0:grass 60:stone 120:crypt` — с какой колонки какая тема |
| `music` | файл музыки `.ogg` или `.mp3` внутри мода (зацикливается) |

### Символы карты

```
#  твёрдый блок                 -  сквозная платформа (запрыгивают снизу)
^  шипы                         +  аптечка
o  пила                         *  шипастый шар на цепи (под потолком)
f  огненная ловушка (вместо блока пола)       T  батут
E  выход (дверь)                P  игрок (ровно один!)
.  (или пробел) пусто
```

Встроенные враги: `s` слизняк, `b` мышь, `k` скелет, `g` гоблин, `m` грибник, `r` крыса, `c` мимик (сундук),
`p` панцирник, `z` зомби, `y` могильный зомби, `x` зомби-рыцарь. Встроенные боссы: `M` Король-гриб,
`N` Костяной рыцарь, `O` Око бездны, `W` Огненный червь, `V` Тёмный колдун, `B` Древний слизень,
`K` Царь-Панцирь, `Z` Король зомби. Плюс символы **ваших** врагов и боссов.

Персонаж или предмет стоит на нижнем краю своей клетки, то есть **на блоке под ней**. По краям карты — невидимые
стены, падение ниже карты — смерть. Карта не меньше 27×16 клеток (иначе камера покажет пустоту) и не больше 1500×300.

На уровне должны быть **игрок `P` ровно один** и **выход `E` или босс** — иначе уровень не загрузится или его нельзя
пройти. Неизвестные символы игра заменит пустотой и покажет предупреждение в разделе «Моды».

### Формат json

То же самое, но карта — массив строк: `{"title": "…", "theme": "stone", "win_boss": "L", "map": ["....", "..P."]}`
(`boss_arena` — объект `{"M": 12}`, `zones` — `[[0, "grass"], [60, "stone"]]`).

### Как сделать проходимый уровень

Игрок запрыгивает на **2 блока** вверх и перепрыгивает яму шириной **3 клетки** (4 — уже нет); 3 блока вверх — нельзя, нужны
ступени из платформ `-` через каждые 2 клетки. Шипы шире 2 клеток с места не перепрыгнуть. Рядом с аренами боссов
кладите аптечки `+`. Если у вас есть исходники игры, **проверить проходимость автоматически** можно так
(нужен Node.js):

```
node tools/validate_levels.js mods/my_mod/levels/01_start.txt
```

Скрипт сам читает символы ваших врагов и боссов из `enemies/` и `bosses/` рядом и находит, до чего игрок не доберётся
(выход, босс, аптечки).

## 7. Скрипты (GDScript)

Скрипты нужны, когда данных недостаточно. Язык — GDScript (как в Godot 4.3), файлы `.gd` в `scripts/`.
Скрипты запускаются, только если игрок включил мод и подтвердил предупреждение.

### Скрипт мода — хуки на события

Файл, указанный в `scripts` в `mod.json` (по умолчанию `scripts/main.gd`), начинается с `extends ModScript`
(**без** `class_name`). Переопределите нужные хуки:

```gdscript
extends ModScript

var kills := 0

func _mod_ready() -> void:
    kills = int(load_data().get("kills", 0))

func _level_started(_level) -> void:
    hint("Жажда крови: за каждого убитого врага +3 здоровья")

func _enemy_killed(_enemy, _power_reward) -> void:
    kills += 1
    var player = get_player()      # без типа: у игрока есть heal()
    if player != null and not player.is_dead():
        player.heal(3)
    save_data({"kills": kills})
```

**Хуки** (названия начинаются с `_`; ненужные не пишите):

| Хук | Когда |
|---|---|
| `_mod_ready()` | мод подключён (при запуске игры или включении) |
| `_level_started(level)` | уровень собран, игрок и враги на местах |
| `_level_completed()` | уровень пройден (или выиграна игра) |
| `_enemy_spawned(enemy, symbol)` | появился враг/босс (в том числе встроенный; `symbol` — символ на карте, у призванных пусто) |
| `_enemy_killed(enemy, power_reward)` | убит враг |
| `_boss_defeated()` | побеждён босс |
| `_player_spawned(player)` | игрок появился на уровне |
| `_player_died()` | игрок погиб |
| `_setting_changed(id, value)` | игрок поменял настройку мода в меню (API 2); `value` — уже проверенное значение |

Это обычный узел: работают `_process(delta)` и `_physics_process(delta)`.

**Помощники** (методы `ModScript`):

| Метод | Что делает |
|---|---|
| `get_player()`, `get_level()` | игрок и узел уровня (null в меню) |
| `spawn(symbol, tile_x, tile_y)` | ставит врага/босса (свой или встроенный) в клетку карты, возвращает узел |
| `hint(text)` | сообщение игроку вверху экрана |
| `read_text(path)`, `load_texture(path)`, `load_audio(path)` | файлы мода (пути от корня мода) |
| `load_frames(spec)` | собирает `SpriteFrames` из описания спрайта (как в разделе 3) |
| `register_symbol(symbol, factory)` | добавляет символ карты: `factory()` возвращает `Node2D` |
| `get_setting(id)` | значение настройки мода (API 2): `true/false`, номер варианта (`choice`) или число (`number`) |
| `lock_difficulty(d)` | (API 2) фиксирует сложность забегов, пока мод включён: `Game.Difficulty.EASY/NORMAL/HARD` = 0/1/2; `-1` снимает фиксацию |
| `set_permadeath(on)` | (API 2) «смерть — конец забега»: после гибели игроку доступны только «начать игру с 1 уровня» (или кампанию мода с начала) и выход в меню; «Продолжить» стирается, перезапуск уровня (R и пауза) отключён |
| `save_data(dict)`, `load_data()` | сохраняют/читают данные мода между запусками |
| `log_message(text)` | строка в журнал (консоль) |
| `mod` | сведения о моде: `mod.id`, `mod.title`, `mod.files` |

Узел уровня (`get_level()`) умеет **`require_clear_all(true)`** (API 2): выходы закрыты, пока на уровне есть враги, а победа над главным боссом (`win_boss` или единственный босс без выхода) засчитывается, только когда не останется ни одного врага; в HUD появляется счётчик «Врагов осталось».

Полезные объекты игрока: `player.health`, `player.heal(n)`, `player.add_power(n)`, `player.take_damage(n, from_position)`,
`player.is_dead()`, `player.get_center()`. Глобальные синглтоны: `Game` (сигналы `hint`, `enemy_killed`, …, `Game.tiles(n)` —
клетки в пиксели), `Sound` (`Sound.play("punch")`), `Mods`.

### Скрипт врага или босса

В `enemies/*.json` / `bosses/*.json` можно указать `"script": "scripts/my_enemy.gd"`. Скрипт должен расширять тот же
класс, что и враг этого вида: **`WalkerEnemy`** для врагов из `enemies/`, **`ModBoss`** для боссов из `bosses/`
(можно и `Boss`, `Enemy` — но тогда вы пишете поведение с нуля). Числа из JSON применяются поверх.

```gdscript
extends WalkerEnemy

func _on_damaged(amount: int) -> void:
    super(amount)
    move_speed_tiles *= 1.15      # от каждого удара бегает быстрее
```

Что полезно знать про базовые классы (`Enemy`, `WalkerEnemy`, `Boss`, `ModBoss`): `max_health`, `health`, `move_speed_tiles`,
`attack_damage`, `facing`, `velocity`, `smart` (умный ли враг на этой сложности), `get_player()`, `distance_to_player_tiles()`,
`set_state(...)`, `queue_action(delay, callable)` (выполнить через delay секунд, если состояние не сменилось), `strike_player(range_tiles, damage)`,
`take_damage(amount)`, `die()`; боссам доступны `restart_timer(name, s)` / `timer_ready(name)`, `spawn_minions(scene, count)`,
`is_enraged()`. Снаряд: `EnemyProjectile.launch(parent, from, velocity, frames, options)`; волна по земле: `Shockwave.new()`;
красная метка на полу: `GroundWarning.spawn(parent, position, seconds)`.

### Что запрещено

Игра читает код скрипта (без комментариев и текста в кавычках) и **не загружает** скрипт, в котором есть:
`OS`, `FileAccess`, `DirAccess`, `HTTPRequest`, `HTTPClient`, `TCPServer`, `StreamPeer*`, `PacketPeer*`, `UDPServer`, `WebSocket*`,
`ClassDB`, `JavaScriptBridge`, `ProjectSettings`, `GDExtension*`, `ResourceSaver`, `ResourceLoader`, `Expression`, `GDScript`,
`Thread`, `DisplayServer`, `IP`, `Engine.get_singleton(...)` и ещё несколько. Для хранения данных есть `save_data()`/`load_data()`,
для файлов мода — `read_text()` и `load_texture()`.

Ещё правила: у скрипта **нет `class_name`**; размер скрипта до 200 КБ; ошибки компиляции видны в разделе «Моды» и в консоли.

## 8. Безопасность (для игроков и авторов)

* Мод **без скриптов** — это только данные (картинки, числа, карты): он не может ничего запустить.
* Мод **со скриптами** — это код. Игра блокирует очевидно опасные вызовы (список выше) и спрашивает вас перед
  включением, но **это не песочница**: GDScript нельзя полностью изолировать. Ставьте моды со скриптами только от авторов,
  которым доверяете, и лучше смотрите исходник `scripts/*.gd` (он открытый текст, а `.zip` открывается любым архиватором).
* Установка по ссылке принимает только `https`, скачивает файл, проверяет `mod.json` и **не запускает** ничего
  без вашей галочки.
* Авторам: не обфусцируйте код и не прячьте обращения к системе — такой мод всё равно не загрузится.

## 9. Упаковка и публикация

1. Проверьте мод у себя: папка в `mods/` → «Моды» → галочка → «Играть». Ошибки и предупреждения показаны справа в меню.
2. Заархивируйте **содержимое** папки мода в `.zip` (при открытии архива сразу виден `mod.json`; одна папка-обёртка допустима).
3. Дайте файл друзьям или выложите на любой сайт — игроки установят его кнопкой «Установить из файла…» или «Установить
   по ссылке». Повторная установка того же `id` обновляет мод.
4. В `mod.json` увеличивайте `version` при обновлениях.

## 10. Диагностика: что значат сообщения

Сообщения видны в разделе «Моды» справа (красным — ошибки, ниже — предупреждения) и в консоли.

| Сообщение | Что делать |
|---|---|
| «mod.json не читается» | проверьте запятые и кавычки (формат JSON); лишняя запятая в конце списка — частая причина |
| «id мода … не подходит» | `id`: 2–40 символов, строчные латинские буквы, цифры, `_`, `-` |
| «мод сделан для более новой версии модов» | уменьшите `api` или обновите игру |
| «символ … занят игрой» / «уже занят другим врагом этого мода» | выберите другую букву |
| «symbol должен быть одним символом» | в `symbol` ровно один символ |
| «не удалось загрузить картинку …» | неверный путь или файл не PNG/WebP/JPG |
| «неверный размер кадра» | `frame` больше картинки по высоте |
| «у босса нет ни одной атаки» | добавьте `attacks` или свой `script` |
| «неизвестный тип атаки» / «pattern снаряда … неизвестен» | допустимые значения — в разделе 5 |
| «на карте должен быть ровно один игрок P» | у уровня один `P` |
| «нет выхода E и боссов — уровень не пройти» | добавьте `E` или босса |
| «неизвестные символы на карте» | опечатка или враг из другого мода/не загружен |
| «скрипт … использует запрещённое» | уберите упомянутый вызов (раздел 7) |
| «настройка …: id … не подходит» / «тип … неизвестен» / «у choice нужен список options…» / «max должен быть больше min» / «id повторяется» | поправьте запись в `settings` (раздел 2); остальные настройки работают |
| «скрипт … не компилируется» | подробности — в консоли игры (строка с ошибкой GDScript) |
| «скрипт … должен начинаться с extends ModScript» | точка входа в `scripts` — это скрипт мода, а не врага |

Одна неработающая часть (враг, уровень, скрипт) **не отключает весь мод** — она пропускается, остальное работает.

## 11. Для тех, у кого есть исходники игры

* Менеджер модов — `scripts/autoload/mods.gd` (поиск, манифест, враги/боссы/уровни, скрипты, установка).
* Файлы мода (папка или zip) — `scripts/mods/mod_files.gd`; спрайты — `mod_sprites.gd`; база скриптов — `mod_script.gd`.
* Декларативный босс — `scripts/enemies/mod_boss.gd`; шаблоны сцен — `scenes/mods/`.
* Кампании модов — `Game.start_campaign()` / `Game.level_data()`; экран — `scripts/ui/mods_menu.gd`.
* Проверка проходимости уровней модов — `tools/validate_levels.js` (принимает `.txt`/`.json` и читает символы из `enemies/`, `bosses/`).
