# Папка модов

Сюда кладутся моды: папкой или `.zip`-архивом (внутри должен быть `mod.json`).
Игра находит их сама — открой «Моды» в главном меню и поставь галочку.

* `_template/` — шаблон для своего мода (папки с `_` игра пропускает): скопируй и переименуй;
* `frost_crypt/` — пример мода без кода (враги, босс, уровни);
* `vampire_rage/` — пример мода со скриптами.

Полная инструкция — `MODDING.md` в корне проекта.

Для обычной (собранной) игры папка `mods` лежит **рядом с exe**; кроме неё игра смотрит в папку пользователя
(`%APPDATA%\Godot\app_userdata\ShootIn\mods`) — туда ставит меню «Моды → Установить…».
